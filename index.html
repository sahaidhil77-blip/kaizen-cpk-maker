tutorial

cara memakai ketiga fitur, langkah demi langkah.

↙ extract & ganti file
  1. buka tab Extract, tekan pilih file, lalu pilih arsip .cpk.
  2. tunggu daftar file muncul. ketik di kolom filter untuk menyaring, mis. .usm atau chr/.
  3. tekan Unduh yang tampil (.zip) untuk menyimpan semuanya, atau ekstrak ke folder.
  4. mau mengubah isi CPK? tekan Ganti atau Hapus di file itu, atau + tambah file ke CPK. Lalu isi nama CPK baru dan tekan Simpan CPK baru.
  5. mode ganti di tempat (disarankan) menjaga struktur CPK dan hanya mau file pengganti yang tidak lebih besar. Matikan kalau pengganti lebih besar, atau kalau mau tambah/hapus file.
↗ create
  1. buka tab Create, lalu tekan + file atau + folder.
  2. isi nama arsip dan pilih alignment (2048 adalah standar CRI).
  3. centang kompres CRILAYLA kalau mau file lebih kecil (build lebih lama), dan pertahankan nama folder induk kalau nama folder harus ikut.
  4. tekan Buat CPK. hasilnya diverifikasi otomatis, lalu siap diunduh.
⇄ merge xfbin
  1. buka tab Merge, tekan file utama, pilih XFBIN utamanya.
  2. tekan + file sumber dan pilih satu atau lebih XFBIN yang mau digabung.
  3. atur opsi: abaikan baris kosong, lewati teks rusak, dan cara menangani entri bernama sama tapi isi beda.
  4. mau ganti kode karakter? pilih karakter, ketik kode tujuan (mis. 2pea), tekan Ubah kode.
  5. isi nama file hasil, lalu tekan Gabungkan & simpan.
tips: geser kartu, atau seret gelembung kaca di menu bawah, untuk pindah tab.
